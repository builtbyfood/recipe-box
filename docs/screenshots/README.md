# Screenshots

Drop PNG files in this folder with the exact filenames below. The
README image references match these names so they render
automatically once committed.

Recommended dimensions: 1080px wide for mobile shots, 1440px wide for
desktop. Compress with TinyPNG or similar before committing — keeps
the repo lean.

## Required (top of README)

- **`hero.png`** — banner shot. Either:
  - A side-by-side composite of library + detail view, OR
  - A clean library shot showing food background, glassmorphism cards,
    and a scattering of recipe tiles
  - Aspect ratio roughly 2:1 looks best in GitHub README rendering

## Recommended (referenced in README)

- **`library.png`** — mobile library view with toolbar, chips, and a
  few recipe tiles all visible
- **`shopping-panel.png`** — detail view with the **Send to list**
  panel open, showing compact/full toggle, editable rows, "already on
  list" indicator
- **`detail.png`** — recipe detail view with hero, description, facts
  strip, ingredients, instructions
- **`cook.png`** — cook mode in full screen, big step text, ingredient
  checklist at top
- **`import.png`** — import dialog with all three tabs visible
  (URL / Paste text / PDF or Photo)
- **`edit.png`** — edit mode of a recipe, showing the Image URL field
  with preview thumbnail, tag chips, and ingredient list editing
- **`share-sheet.png`** — Android share sheet showing the "Home
  Assistant" option highlighted (partial screenshot is fine)
- **`import-notification.png`** — Companion app notification after a
  successful import, ideally with the "Open" action button visible

## Optional polish

- **`groups.png`** — library with `By tag` grouping, multiple section
  headers visible
- **`list-mode.png`** — list-view toggle, dense rows
- **`cook-again.png`** — cook-again carousel above the main library

Once committed, GitHub renders them inline. No build step.
